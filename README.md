# 算法与智能体实验室

这是一个使用 Hexo 7 和 Butterfly 5.7.0 搭建的中文技术博客，文章覆盖代码实践、Agent 工程和算法笔记。

## 本地启动

```bash
npm install
npm run server
```

打开 <http://localhost:4000/> 即可预览。

## 常用命令

```bash
npm run clean   # 清理生成缓存
npm run build   # 生成 public/ 静态文件
npm run server  # 启动本地开发服务器
```

文章放在 `source/_posts/`，站点配置在 `_config.yml`，主题源码位于 `themes/butterfly/`。
